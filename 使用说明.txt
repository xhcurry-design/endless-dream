无尽梦境 - Windows / macOS 离线便携版

运行要求
1. Windows 10 / 11（64 位，支持 x64 和 ARM64），或 macOS 12 及以上版本（支持 Intel 和 Apple 芯片）。
2. 推荐使用最新版 Chrome、Edge 或 Safari，并确保浏览器支持 WebGL2。
3. 完整游玩需要键盘和鼠标。界面可以在手机尺寸下显示，但目前不提供触屏移动操作。
4. 解压后请保留完整文件夹结构，不要只复制 HTML、GLB、SOG 或其他资源文件。

Windows 启动
1. 双击“启动游戏.bat”。
2. 保持弹出的服务窗口开启；浏览器会自动打开游戏。
3. 关闭服务窗口或按 Ctrl+C 即可停止游戏服务。

macOS 启动
1. 在 Windows 中发送游戏前，双击“生成跨平台分享包.bat”。
2. 将生成的压缩包直接发给对方，不要再次压缩。
3. 在 Mac 中解压后，双击“启动游戏.command”。它会自动选择 Intel 或 Apple 芯片对应的服务器并打开浏览器。
4. 如果 macOS 首次运行时显示安全拦截，请在 Finder 中按住 Control 点按“启动游戏.command”，选择“打开”；后续可直接双击。
5. 关闭终端窗口或按 Control+C 即可停止游戏服务。

本地服务
本地服务器默认从 8137 端口启动；如果端口被占用，会自动尝试后续 20 个端口。请勿直接双击 run\main_pro.html；场景、模型和碰撞资源必须通过随包自带的本地服务器加载。运行游戏不需要安装 Python、Node、Go 或其他开发环境，也不需要联网。

进入游戏
1. 封面显示《无尽梦境》，点击“进入梦境”开始。
2. 黑猫会从房间里走近玩家，并进行五句开场对白。每句话播放完整后，点击右下角箭头，或按 E、Enter、空格继续；开场对白不能跳过。
3. 对话结束后会显示主房间玩法说明，左上角目标会继续引导当前任务。点击游戏画面可锁定鼠标，按 Esc 打开暂停菜单并释放鼠标。

右上角游戏工具
- 按键说明：随当前密室显示实际可用的移动、观察与解谜按键。
- 游戏指南：查看当前密室的目标和分步玩法；进入新的密室时会自动显示一次。
- 暂停游戏：暂停移动、视角、动画与倒计时，并释放鼠标；点击“继续游戏”后再点击画面即可继续。
- 重新开始：主房间会重新开始整场梦境；密室内会重新开始当前房间，并在执行前要求确认。
- 按 Esc 也可打开或关闭暂停菜单。工具栏与弹层在窄屏下会自动收紧，但完整游玩仍需要键盘和鼠标。

主房间操作
- WASD / 方向键：移动
- 鼠标：转动第一人称视角
- Shift：奔跑
- 空格：跳跃
- E：靠近镜面、向日葵等互动点时互动

完整流程
1. 先靠近镜面，进入第一重梦“逐光温室”。
2. 完成镜面解谜并从打开的门返回主房间，获得手持道具“镜生花”。
3. 拿着镜生花靠近窗前向日葵并按 E。镜生花会被消耗，通往后两重梦的通道才会开启。没有先取得花时，黑猫会给出提示，玩家不会被提前传送。
4. 完成倒置房间与储藏室原有解谜，取得“日照钥匙”并返回主房间。钥匙会显示在玩家手中。
5. 完整观看黑猫的三句返场对白，然后拿着钥匙靠近最初醒来时身后的门。无需按键，靠近后会自动触发结局。
6. 胜利画面会显示通关时间与三段旅程回顾，可选择“再次入梦”或“返回封面”。

逐光温室操作
- 点击画面：锁定鼠标
- WASD：移动
- 鼠标：转动第一人称视角
- E：靠近镜架后接手或放开镜子
- J / L：接手镜子时，让镜面向左 / 向右偏转
- I / K：接手镜子时，让镜面上抬 / 下压
- R：重置这一重梦

逐光温室目标
调整镜面，将反射光按顺序照亮三朵向日葵。三朵花全部苏醒后，门上的藤蔓会枯萎，门会打开；走进打开的门即可返回主房间并取得镜生花。

倒置房间操作
- 点击画面：锁定鼠标
- WASD：移动
- 鼠标：转动第一人称视角
- Shift：加速移动
- Q：切换阳光 / 阴暗模式
- E：观察并收集准星对准的异常物件

倒置房间目标
先观察阳光模式下的房间，再切换到阴暗模式寻找 3 件不该存在的异常物件。靠近并将准星对准异常物件后按 E 收集；三件全部收集后，房间会自动淡出并进入储藏室。

储藏室操作与目标
- WASD：移动
- 鼠标：转动视角和手电方向
- Shift：加速移动
- E：净化已显形的节点，或拾取日照钥匙
- R：挑战失败后重新开始储藏室谜题

按界面提示依次用手电照住 3 道光痕，使对应的净化节点显形；靠近节点、将准星对准后按 E 净化。注意倒计时和扩散的污染。净化全部 3 个节点后，日照钥匙会出现在房间中心；靠近并按 E 拾取后会立即淡出并返回主房间。

倒置房间完成倒转并进入储藏室后，会再次显示储藏室专属玩法说明。阅读说明期间游戏处于暂停状态，倒计时不会提前消耗。

进度说明
同一个浏览器标签页内，跨房间与刷新页面会保留本轮进度。“再次入梦”和“返回封面”会清除本轮进度；关闭浏览器标签页后，临时进度也可能结束。
